# 项目状态与架构

## 当前状态

- 公开仓库：<https://github.com/weijh163-png/haoge-workspace>
- GitHub Pages：<https://weijh163-png.github.io/haoge-workspace/>
- 发布分支：`main`
- 技术形态：静态 HTML、CSS、JavaScript，无打包器、数据库或后端。
- 根入口：`index.html`

工作台保留原有收入核算、月度工作流、报表、项目台账和复盘功能。税务师考试区域已经扩展为三科完整学习台；进入后顶部固定栏可以直接切换三科，不需要返回工作台。考试弹窗以税务师为主要内容，中级经济师只作弱提醒。

## 数据边界

根工作台与三科学习进度均使用浏览器本地存储，不存在服务器同步：

- 税法一：`tax1state`
- 税法二：`tax2state`
- 涉税服务实务：`taxPracticeState`

切换科目只替换 iframe 页面，不清除上述状态。不要把学习进度与工作台业务数据合并，也不要宣称记录会跨设备同步。

## 内容依据

三科结构以中国注册税务师协会《2026年度税务师职业资格考试大纲》为准，政策法规截止日期为 2026 年 3 月 31 日。税法二和涉税服务实务的注意力比重综合用户提供的 2026 三色笔记与高频考点资料；其中高频资料主要基于 2025 教材，只用于历史考情权重，不能替代 2026 官方口径。

三科“备查资料”均在本地整理标题和官方链接。第三方政策目录不作为权威依据，也不作为运行时依赖。

## 已知约束

- 根 `index.html` 较大，修改时应使用精确定位并运行 JavaScript 语法检查。
- 税法一是独立页面；税法二与实务由同一共享组件渲染，修改共享文件会同时影响两科。
- GitHub Pages 站点位于仓库子路径，禁止使用以 `/` 开头的站点根绝对资源路径。
- 辅导 PDF、历史备份、临时目录和旧 ZIP 不属于线上有效源码。
