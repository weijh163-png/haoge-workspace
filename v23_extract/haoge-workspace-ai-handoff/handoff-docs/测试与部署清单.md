# 测试与部署清单

## 修改前

```powershell
git status --short
git log -5 --oneline
```

确认工作区是否有用户未提交的改动。不要使用会丢失改动的重置或检出命令。

## 自动化回归

在仓库根目录执行：

```powershell
node tests/tax-integration.test.cjs
Push-Location haoge-src
node tests/workbench.test.cjs
Pop-Location
git diff --check
```

税务集成测试应覆盖：

- 三科入口与工作台内部打开。
- 顶部三科切换、当前科目活动态和当前科目不重复加载。
- 税务师优先排序与中级经济师弱提醒。
- 每科规定学习区域、题目数、阶段数和章节权重。
- 三个独立存储键及存储不可用时的降级。
- 无远程运行时资源，GitHub Pages 相对路径可用。

## 浏览器检查

至少验证以下路径：

1. 首页打开“税务师考试”，税务师卡片在前，中级经济师位于下方并显示“仅提醒 · 今年不备考”。
2. 进入税法一，依次切换到税法二和涉税服务实务，过程中不返回工作台。
3. 工具栏当前科目高亮，标题和 iframe 内容一致。
4. 税法二答错一题后进入错题本，刷新后错题仍存在；其他科目不出现该错题。
5. 三科“备查资料”可打开，官方链接使用新标签页。
6. 窄屏下科目切换与底部学习导航可横向滚动，页面无整体横向溢出。

## 更新交接包

```powershell
pwsh -NoProfile -File handoff/build-handoff.ps1
```

脚本会重建 `handoff/浩哥工作台-AI交接包.zip` 和 `handoff/文件清单及校验值.txt`。生成后检查 ZIP 可解压，且不含 PDF、`.git`、临时文件、历史备份或凭据。

## 提交与推送

```powershell
git add <本次文件>
git commit -m "描述本次变更"
git push origin HEAD:main
```

只使用本机已有 GitHub 认证。禁止把令牌写入命令、远程 URL、配置文件或文档。
