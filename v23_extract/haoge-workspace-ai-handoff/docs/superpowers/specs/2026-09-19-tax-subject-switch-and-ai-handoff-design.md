# 税务师科目切换与 AI 交接包设计

## 目标

在不改变现有工作台主体结构的前提下，让用户进入任一税务师学习页后可直接切换三科；同时降低中级经济师提醒的视觉优先级，并生成可交给其他 AI 继续维护和推送的公开仓库交接包。

## 范围

本次包含：

- 工作台内嵌学习页顶部的三科固定切换栏。
- 税务师考试卡片置顶，中级经济师提醒下移并弱化。
- `handoff/` 中可阅读的交接文档、精简源码 ZIP 和校验清单。
- 自动化回归、真实浏览器检查、GitHub Pages 发布验证。

本次不包含：

- 修改各科知识内容、题目、章节权重或存储格式。
- 把四份辅导 PDF 上传到仓库或 ZIP。
- 保存或分发 GitHub Personal Access Token 等凭据。
- 删除中级经济师倒计时。

## 科目切换设计

### 位置与结构

科目切换位于工作台全屏学习视图的固定顶部栏，排列在“返回浩哥工作台”与当前科目标题之间。按钮顺序固定为：

1. 税法一
2. 税法二
3. 涉税服务实务

桌面端显示为紧凑的分段按钮；窄屏允许横向滚动，不能挤压返回按钮或造成整页横向溢出。

### 行为

- 点击当前科目不重新加载，避免不必要的页面刷新。
- 点击其他科目调用现有 `openSubjectStudy` 流程，在同一个 iframe 中切换本地页面。
- 工具栏标题、摘要、iframe 标题和活动按钮同步更新。
- 切换不清除 `tax1state`、`tax2state`、`taxPracticeState`，三科进度继续隔离。
- 加载失败时继续显示重试与返回入口；重试当前所选科目。
- `aria-current` 标记当前科目，便于键盘和辅助技术识别。

## 考试提醒排序

考试倒计时弹窗中，税务师卡片调整到首位并保持主要视觉层级。中级经济师卡片移到税务师卡片之后，改为较紧凑、低饱和度的提醒样式，文案明确为“仅提醒 · 今年不备考”。倒计时日期和计算逻辑保留。

## AI 交接包设计

### 仓库位置

在同一公开仓库新增 `handoff/`：

- `从这里开始.md`：给人和 AI 的第一入口。
- `给其他AI的接手提示.md`：可直接复制为新任务提示。
- `项目状态与架构.md`：当前线上版本、目录职责、存储键、来源口径和已知约束。
- `测试与部署清单.md`：本地检查、Git 命令、Pages 验证和失败处理。
- `文件清单及校验值.txt`：ZIP 内文件及 SHA-256。
- `浩哥工作台-AI交接包.zip`：精简、可移交的源码快照。

### ZIP 内容

ZIP 包含当前有效版本所必需的内容：

- 根目录 `index.html`、`README.md`。
- `tax-law-one/`、`tax-law-two/`、`tax-service-practice/`、`study/`。
- `tests/tax-integration.test.cjs`。
- 与本次税务学习功能相关的设计规格。
- ZIP 内专用的 `从这里开始.md`。

ZIP 排除 `.git`、四份 PDF、Token、浏览器数据、本地存储数据、临时目录、历史 HTML 备份、旧 ZIP 和无关生成器。源码快照不携带 Git 历史；接手 AI 应优先克隆公开仓库，ZIP 用于上下文缺失或离线移交。

### 凭据规则

文档只能记录仓库 URL、默认分支和标准推送命令，不能包含 PAT、密码或授权头。推送依赖接手环境已有的 GitHub 登录状态；无权限时应请求用户在本机完成认证。

## 验证

- 扩展税务集成测试：三科切换按钮、活动态更新、考试排序、弱化提醒文案、存储隔离。
- 执行 `node tests/tax-integration.test.cjs`。
- 执行 `haoge-src/tests/workbench.test.cjs`，确保工作台原功能无回归。
- 检查 ZIP 可正常解压，关键文件存在，清单中的 SHA-256 与文件一致。
- 扫描 `handoff/`，确认不存在 GitHub 令牌、Personal Access Token、PDF 文件或用户本地绝对路径中的凭据。
- 在真实浏览器验证三科无需返回工作台即可连续切换，并检查加载失败回退。
- 推送 `main` 后等待 GitHub Pages 成功，再校验线上首页、三科页面和共享资源均返回 200。

## 完成标准

用户可在任一税务师学习页顶部直接切换三科；税务师在考试弹窗中位于第一优先级，中级经济师仍有但仅作弱提醒；另一 AI 读取 `handoff/从这里开始.md` 或 ZIP 后，无需猜测即可运行、测试和按安全规则继续维护本仓库。
