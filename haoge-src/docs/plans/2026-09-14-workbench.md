# 收入核算工作台 Implementation Plan

> 按用户已确认的方案执行；保持现有单文件应用，不创建新框架或替换业务规则。

**Goal:** 落实淡蓝横向工作台、清晰的模块排版、外部 AI 办理入口及可靠的按月项目状态。

**Architecture:** 在最新交接 HTML 的工作区副本上增量修改，原文件及本轮备份保持不变。现有业务数据继续保留；按月状态通过统一月份容器保存，历史未了单独持续跟踪。所有外部 AI 操作由用户点击触发，未配置时给出手动指引。

**Tech Stack:** 单文件 HTML / CSS / Vanilla JavaScript / localStorage；Node 本地自动化测试。

- 目标：`浩哥工作台.html`；回退：`浩哥工作台-本轮修改前备份-20260914.html`。

- 验证：切月隔离、刷新重开、旧数据兼容、损坏数据和保存失败提示。

### 2. 项目台账
- 项目列表增加搜索、组合筛选、详情、按月处理状态、备注、完成时间。

- 验证：直接完成及撤销、跨月隔离、文本安全、无匹配结果。

### 3. AI 辅助与扎口未了

- 验证：无旧工具入口、链接校验、复制失败回退、点击不算完成。
