# 给其他 AI 的交接说明

## 目标

在不破坏现有功能和业务规则的前提下，继续维护或扩展“浩哥工作台”。这是收入会计的本地离线工作台，核心是：今日待办、月度流程、AI 辅助、报表自动化、项目台账、流程图复盘、扎口与未了，以及税务师考试提醒。

## 运行与修改边界

- 入口文件是 `浩哥工作台.html`，可直接在浏览器离线打开。
- 页面业务状态保存在浏览器 `localStorage`，不要把页面数据改为云端同步，除非使用者明确授权并确认数据安全方案。
- 优先修改 `src/` 中的对应源码；同步回单文件页面前，先用 `node scripts/patch-section.cjs <任务名>` 生成补丁，再通过补丁方式应用，避免手工编辑造成源码与页面不一致。
- Excel 自动化仅处理营业额导入与核验；成本费用由成本会计负责，不应擅自调整成本逻辑。
- 保留项目台账中的项目名称、窗口、责任人等原始业务字段；页面其他位置的人名使用“浩哥”，复核角色使用“复核人”。

## 视觉基调：天青烟雨

- 整体为低刺激的天青、雾青、暖白体系，不使用高饱和蓝光。
- 背景由 `src/comfort.css` 和 `src/init.js` 实现：半透明雾层、缓慢漂移的白雾、随机位置与轨迹的毛玻璃雨滴。
- 雨滴必须保持随机生成与连续流动；尊重 `prefers-reduced-motion`，降低动态效果时不应影响内容阅读。
- 内容卡片保持温和的半透明白色，正文用深灰绿，强调色仅用于状态、按钮与少量分区提示。
- 页面优先保证效率：信息层级清楚、留白充足、避免密集流水账式排版和过多高亮色。

## 主要模块

1. **首页 · 今日**：只呈现今天关键事项、待催办、月度节奏和异常说明提醒。
2. **月度工作流程**：月度关键节点与日常例行工作分区展示，日常事项不应挤入月度节点。
3. **AI 辅助系统**：业务规则与核对指引；AI 操作入口以提醒和跳转为主，不应自动上传业务数据。
4. **报表自动化**：七份月度报表的进度、交接与异常说明；当前重点是营业额导入和核验。
5. **项目台账**：项目状态可标记；项目名称和责任人字段须忠实保留台账原始数据。
6. **流程图与复盘 / 扎口与未了**：流程可视化、月度复盘和未了事项跟踪。

## 可直接复制给其他 AI 的提示词

```text
请接手这个“浩哥工作台”项目。先阅读 README.md、给其他AI的交接说明.md、使用说明.md，并检查 浩哥工作台.html 与 src/ 的对应关系。

这是收入会计的离线工作台。保持现有功能、中文文案、业务数据和本地存储机制不变；若要改动，请优先提升效率、可读性与低刺激视觉体验。特别保留“天青烟雨”主题：雾青背景、毛玻璃雨滴、白雾缓慢流动、内容卡片温和透白，禁止恢复刺眼的蓝色高光或密集排版。

Excel 自动化只处理营业额数据的导入和核验，不能推断或改写成本会计逻辑。涉及项目台账时保留项目原始人名与字段；其他页面称呼使用“浩哥”，复核角色显示“复核人”。

修改前先说明影响范围；修改后同步源码与单文件页面，并运行 tests/ 中的检查。若需要把数据接入任何云端服务，先说明数据字段、传输范围、权限与备份方案，等待确认后再实施。
```

## 自检

在 Windows PowerShell 中，进入本目录后可运行：

```powershell
node tests/workbench.test.cjs
python tests/html_structure.py
```

若本机没有 Python 或 Node，仍可以直接打开 HTML 使用；只是无法执行自动化检查或脚本。
