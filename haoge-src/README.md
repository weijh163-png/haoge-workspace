# 浩哥工作台｜完整可复用副本

这是可交给其他 AI 或开发者接手的离线工作台副本，保留当前界面、业务模块、收入报表自动化脚本、测试和已交付的 Excel 模板。

## 直接使用

双击打开 `浩哥工作台.html` 即可离线运行，无需安装依赖。页面填写的数据保存在浏览器本机的 `localStorage` 中；换电脑或换浏览器前，请在页面中使用“备份”功能导出记录。

## 包含内容

| 位置 | 用途 |
| --- | --- |
| `浩哥工作台.html` | 可直接运行的完整单文件工作台 |
| `src/` | 页面模块、交互和“天青烟雨”主题的可维护源码 |
| `scripts/` | 页面同步辅助脚本、营业额导入与公式模板脚本 |
| `交付/` | 已生成的营业额自动导入与核验 Excel 模板 |
| `tests/` | 页面结构与回归检查 |
| `docs/` | 已有设计、审阅与实施记录 |
| `给其他AI的交接说明.md` | 交接范围、视觉规范和可直接复制的提示词 |

## 注意

`交付/` 内可能含项目、窗口、责任人和营业额等业务数据。上传到云端 AI 前，请先确认单位的数据合规要求；若只需复用界面，请移除 `交付/` 后再发送。
