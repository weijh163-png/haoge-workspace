# 浩哥工作台 AI 交接入口

这是 `weijh163-png/haoge-workspace` 的维护交接包。当前项目是无需构建的静态 HTML/CSS/JavaScript 工作台，线上地址为：

<https://weijh163-png.github.io/haoge-workspace/>

## 接手顺序

1. 阅读 `项目状态与架构.md`，了解有效源码、税务师三科结构和本地存储边界。
2. 阅读 `给其他AI的接手提示.md`，把其中内容作为新任务的初始上下文。
3. 修改前运行 `git status --short`，保留用户已有改动。
4. 修改后按照 `测试与部署清单.md` 完成回归。
5. 仅在用户授权且本机已有 GitHub 认证时推送；不要索取、记录或提交访问令牌。

## 重要边界

- 四份税务师辅导 PDF 不在本包中，也不得提交到公开仓库。
- 学习进度只保存在用户当前浏览器；不要伪造、迁移或覆盖真实进度。
- 税务内容以中国注册税务师协会 2026 年考试大纲及官方现行政策为准。
- `index.html` 是当前线上工作台入口；不要用历史 HTML 备份覆盖它。
- ZIP 是精简快照，优先以公开仓库最新 `main` 分支为准。
